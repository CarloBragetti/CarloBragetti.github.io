# Immagini — articolo "Revisione motore"

Metti qui le foto/screenshot esportati dall'highlight Instagram (sono tue foto).

## Workflow
1. Esporta i fotogrammi dall'highlight (telefono: apri la storia → ⋯ / Salva).
2. Copia i file in questa cartella.
3. Nominali in ordine di racconto, così è facile referenziarli, es.:
   - `01-motore-smontato.jpg`
   - `02-pistoni-usura.jpg`
   - `03-misura-cilindro.jpg`
   - …
4. Avvisami: li inserisco nell'articolo con didascalia e ordine giusto.

## Note tecniche
- Formato: **.jpg** o **.webp** (no HEIC: GitHub Pages non lo mostra nei browser). Se hai HEIC, convertili in JPG.
- Dimensione: vanno bene ~1200–1600 px di lato lungo; non serve la risoluzione piena (alleggerisce il sito).
- Niente dati sensibili nelle foto (targhe, documenti): se ci sono, oscurali.

Le immagini vengono referenziate dall'articolo così:
